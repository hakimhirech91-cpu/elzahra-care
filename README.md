# El-Zahra Connect

أنشئ موقعًا طبيًا احترافيًا وحديثًا ومتجاوبًا بالكامل لعيادة:

**Centre El-Zahra ORL Djelfa**

عيادة متخصصة في طب وجراحة الأنف والأذن والحنجرة (ORL / ENT) في مدينة الجلفة، الجزائر.

### الهدف

إنشاء موقع طبي موثوق وأنيق يعطي المريض جميع المعلومات المهمة بسرعة، ويسهّل عليه التواصل مع العيادة وطلب موعد، مع تصميم يعكس النظافة، الثقة، والاحتراف الطبي.

### الهوية والمعلومات

* الاسم: Centre El-Zahra ORL Djelfa

* الاسم بالعربية: عيادة الزهراء

* التخصص: ORL — طب وجراحة الأنف والأذن والحنجرة

* المدينة: Djelfa, Algeria

* الهاتف: 0697 97 80 15

* العنوان: M7P4+V7 Djelfa

* التقييم الظاهر: 4.3/5 من 9 تقييمات

### التصميم

استخدم تصميمًا طبيًا Premium وهادئًا:

* خلفية بيضاء ونظيفة.

* درجات أزرق طبي مع لون ثانوي أخضر/تركوازي خفيف.

* مساحات بيضاء واسعة.

* بطاقات بسيطة ذات زوايا ناعمة.

* أيقونات طبية حديثة.

* خطوط عربية واضحة وسهلة القراءة.

* دعم كامل للغتين العربية والفرنسية، مع إمكانية إضافة الإنجليزية.

* التصميم يجب أن يكون RTL عند اختيار العربية.

* تجنب التصميم المزدحم أو الألوان الصارخة.

### قسم الخدمات

أنشئ Cards للخدمات الطبية، مثل:

1. **أمراض الأنف والجيوب الأنفية**

   تشخيص ومتابعة مختلف مشاكل الأنف والجيوب الأنفية.

2. **أمراض الأذن والسمع**

   فحص ومتابعة مشاكل الأذن والسمع والتوازن.

3. **أمراض الحنجرة والصوت**

   تقييم ومتابعة اضطرابات الحنجرة والصوت.

4. **فحوصات ORL**

   فحوصات وتشخيصات متخصصة في مجال الأنف والأذن والحنجرة.

5. **طب الأطفال ORL**

   متابعة مشاكل الأنف والأذن والحنجرة لدى الأطفال.

لا تخترع إجراءات أو خدمات جراحية محددة لم يتم تأكيدها. اجعل المحتوى قابلًا للتعديل من لوحة الإدارة.
